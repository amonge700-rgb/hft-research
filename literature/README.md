# Literature

此目录保存可版本控制的文献元数据、BibTeX、阅读笔记和下载清单。

论文 PDF 与 Supporting Information 默认保存在工作区外部的大文件目录，不直接提交 Git。经课题合作、用户明确要求或许可条件确认后需要随项目保存的原文，统一放在 `source_papers/`，并在下表记录用途与来源。
每项模型参数必须能追溯到文献、有限元、实测或明确标注的合成设定。

## 文献使用规则

1. 论文原文只作为方法依据，不能把普通电力变压器的参数直接用于高频变压器；
2. 任富强论文提供的是分布建模思想和矩阵组织方式，高频参数必须由高频文献、COMSOL/FEM或实测重新标定；
3. 实验报告引用文献结论时应记录页码、公式或图表位置；
4. 仓库中的论文文件不代表允许公开再分发，公开发布仓库前应再次核查版权与合作者约定。
