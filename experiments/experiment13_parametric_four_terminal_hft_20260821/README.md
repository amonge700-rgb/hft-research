# EXP-013 参数化四端子分段高频变压器

本实验保留实验 10/11 的四段共同参考模型作为回归基准，另建参数化升级版。

第一阶段目标：

- 原、副边各保留两个独立端子：`p+`, `p-`, `s+`, `s-`；
- 支持任意 `Np`, `Ns` 分段数；
- 支持任意对称正定全耦合电感矩阵 `L`；
- 支持一般稀疏跨绕组电容矩阵 `Cps(i,j)`；
- 支持各段纵向电容和全部节点对机壳参考电容；
- 记录各段电压、电流及每条跨绕组电容支路电流；
- 生成独立的四端子线性验证模型，不覆盖旧 SLX。

入口：

```matlab
cd simulink
run_exp13_build_and_validate
```

生成文件位于 `simulink/generated` 与 `results`。
