# EXP-019A 可学习跨绕组电容耦合选择

## 1. 研究目的

在逐匝全耦合电容矩阵已知的模型级条件下，研究哪些原副边匝间电容边可以在固定边预算内保留，同时最大限度保存端口导纳、内部匝电压和跨绕组位移电流。

该实验把 GNN/AI 的输出从“响应”改为“边的重要性分数”，由 EXP15 精确矩阵/Kron 求解器完成物理解码。

## 2. 待验证假设

- H1：相同边保留率下，可学习门控优于只按距离或电容量级裁剪。
- H2：Fisher 对角/响应灵敏度能够成为强物理基线。
- H3：端口保持与内部电压、位移电流保持并不完全等价，必须多任务评价。

## 3. 模型与数据来源

- 教师：EXP15 匝级矩阵与精确 Kron 求解器。
- 拓扑：4+4、6+6、8+8 匝。
- 激励：DAB 自然奇次 PWM 谐波 1、3、5、7、9 次。
- 数据：合成 Cps 距离核、局部斑块、非对称和总量扰动。
- 边界：不是 COMSOL 或实机实验；没有测量到参数的在线反演。

## 4. 数学方法

网络对每条候选跨绕组电容边输出分数 `s_ij`。训练时使用带预算阈值的软门控，测试时固定保留率执行 hard top-k。保留后的边重新组装电容矩阵，再计算物理响应。

目标函数由端口相对复误差、内部节点复电压误差、跨绕组总位移电流误差和预算约束组成。

## 5. 对照

- `distance`：优先保留轴向位置接近的边；
- `magnitude`：优先保留电容量最大的边；
- `fisher_proxy`：标称条件下单边 log-C 灵敏度平方和；
- `learned_gate`：工况感知的可学习边评分器。

所有方法使用相同 hard edge budget，避免不公平比较。

## 8. 正式结果摘要

正式配置为 150 个训练样本、75 个跨工况测试样本、45 epochs、RTX 5070 CUDA，训练耗时约 187.9 s。固定保留约 39% 的 `Cps` 边时：

| 方法 | 端口响应 MAE | 节点电压 MAE/400V | 位移电流误差 |
|---|---:|---:|---:|
| 距离 | 2.148e-6 | 1.097e-7 | 35.42% |
| 电容量级 | 2.048e-6 | 1.019e-7 | 33.71% |
| Fisher proxy | 约 1.3e-6 | 约 1.1e-7 | 约 29%--30% |
| 可学习门控 | 1.356e-6 | 1.018e-7 | 28.01% |
| 真值边电流 oracle | 1.344e-6 | 1.020e-7 | 27.98% |

可学习门控非常接近 oracle，说明边选择任务已跑通；但 40% 边预算下的位移电流误差仍过大，不满足工程模型要求。预算扫描表明保留约 80% 边时，可学习门控的平均位移电流误差降至 3.60%，说明当前合成 `Cps` 矩阵并不高度稀疏。
