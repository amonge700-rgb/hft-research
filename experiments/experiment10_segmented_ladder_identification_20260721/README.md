# 实验十：DAB 多窗口驱动的分段梯形网络在线辨识

## 1. 研究目标

将当前整体两端口模型

```text
(Rs, Ls, Cps) -> Y12(f)
```

升级为分段双梯形网络

```text
{Ri, Li, Csi, Cgi, Cpsi, Mij} -> Yterminal(f), Uinternal(f)
```

并研究能否利用 DAB 多运行窗口重构的两端口宽频导纳，对局部绕组间电容变化进行定位和定量反演。

## 2. 技术壁垒

本实验不把创新点表述为“使用非线性最小二乘拟合参数”。核心技术链为：

1. 任富强式阻抗支路、导纳支路和拓扑关联矩阵表示；
2. 任意端口激励/边界条件下的统一频域矩阵求解；
3. DAB 多运行窗口下的端口激励矩阵重构；
4. 梯形参数复灵敏度/Jacobian 与 Fisher 可辨识性分析；
5. 健康基准上的局部稀疏漂移反演；
6. 内部节点电压与跨绕组分段位移电流重构。

## 3. 第一阶段模型

第一版使用原副边各 4 个对应单元，合计 8 个串联绕组单元。为了先回答可辨识性问题，不同时释放全部参数：

- 健康基准：`Ri, Li, Csi, Cgi, Cpsi, Mij` 全部已知；
- 在线候选变化：优先只允许 4 个 `Cpsi` 和少量 `Li/Mij` 组合变化；
- 目标：判断 4 个局部 `Cpsi` 的灵敏度列是否可区分，并确定可达到的空间分辨率。

若相邻单元灵敏度高度相关，则自动合并为“首端、中部、末端”等可辨识区域，不强行输出虚假的单元级定位。

## 4. 正向矩阵接口

计划建立统一接口：

```python
response = solve_ladder_frequency(
    frequency_hz,
    topology,
    parameters,
    port_boundary,
)
```

返回：

- 端口导纳矩阵 `Y_port[f, p, p]`；
- 全部节点电压 `U_node[f, node]`；
- 阻抗支路电流 `I_z[f, branch]`；
- 导纳支路电流 `I_y[f, branch]`。

矩阵内核与端口观测、优化器、Fisher/OED、AI 模块解耦。

## 5. 与现有工程的连接

复用现有代码：

- `run_loaded_dab_multiport_cps_identification.py` 中的多窗口激励和两端口导纳重构；
- `run_loaded_dab_forward_model_mismatch.py` 中的测量链路和失配测试框架；
- 现有 Fisher/OED 代码中的复灵敏度和频点选择思想。

替换部分：

- 删除标量 `simplified_y12()` 作为主正向模型；
- 使用梯形网络端口导纳矩阵计算所有 `Y11/Y12/Y21/Y22`；
- 由整体参数拟合改为健康基准上的局部参数漂移反演。

## 6. 反演任务

第一轮依次验证：

1. 已知异常单元，只估计变化幅度；
2. 未知异常位置，四选一定位；
3. 两个单元同时变化，稀疏反演；
4. `Cpsi` 与 `Li/Mij` 同时变化，检验误判风险。

推荐目标函数：

```text
data consistency + group sparsity + spatial total variation + physical bounds
```

即利用健康基准限制变化量，而不是从端口数据中重新估计全部绝对参数。

## 7. 必须输出的结果

- 各局部参数归一化灵敏度随频率变化；
- Jacobian 列相关矩阵；
- Fisher 特征值、条件数和有效秩；
- 局部异常定位混淆矩阵；
- 参数变化幅值误差；
- 内部节点电压重构误差；
- 分段跨绕组位移电流重构误差；
- 与整体三参数模型的对照结果。

## 8. 当前状态

- 已确认现有 DAB 多窗口两端口重构模块可复用；
- 已完成自主重建的四分段高频变压器矩阵正向内核；
- 已完成阻抗矩阵、电容矩阵、关联矩阵与Kron消元数学推导；
- 正向模型已通过互易性、被动性、KCL和端口电流一致性验证；
- 四个局部 \(C_{ps,i}\) 的Jacobian虽满秩，但第2--4段灵敏度相关系数达到0.992--0.996；
- 4800次局部线性反演表明，四单元总体定位率约87.44%，端部/内部区域定位率约93.73%，但局部幅值恢复仍不稳定；
- 下一步：接入DAB多窗口重构，并通过端口、频点、运行窗口和接地观测设计改善内部单元的可分辨性。
