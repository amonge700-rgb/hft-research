## 无界面编译异常

以下三个模型调用

```matlab
set_param(model,'SimulationCommand','update')
```

后均无法在 90–300 s 内返回：

1. 完整四段梯形 Simscape 模型；
2. 只保留八绕组核心的诊断模型；
3. 标准 RC Simscape 控制模型；
4. 纯 Simulink `Sine Wave -> Gain -> Out1` 控制模型。

因此当前阻塞不支持“自定义八绕组方程有误”这一解释，更符合本机 MATLAB
无界面/batch 更新路径异常、许可证交互或桌面服务阻塞。
