# EXP-014 参数化四端子分段 HFT 的 DAB 开关回归

## 目的

在 EXP-013 四端子线性模型之外建立独立 DAB 模型，验证 SPS 相移下的四端子边界、点标记、端口功率方向和开关时域求解。现有线性 SLX 不被覆盖。

## 当前模型边界

- 高频变压器为 8+8 分段，保留完整对称正定 `L`、纵向/对地电容和稀疏非局部 `Cps`；
- 两侧采用功率守恒的理想开关函数全桥和浮置直流源；
- SPS 条件：20 kHz、20°、400 V/100 V；
- 用 1 us 有限边沿避免理想阶跃驱动分布电容产生数学冲激；
- 用 1 GΩ 固定副边共模数值规范，不构成共同功率回路；
- 使用 100 ns Simscape 局部 Backward-Euler 步长；
- 当前为两周期开关回归，不是长时稳态、器件级开关或真实样机验证。

## 复现

在 MATLAB R2021b 中进入 `simulink/`：

```matlab
run_exp14_build_compile
run_exp14_sps_validation
```

## 主要结果

- 编译成功，最近一次编译时间约 6.317 s；
- 一次桥交流吸收功率 -48.109 kW，二次桥 +41.116 kW；
- 当前合成分段网络吸收功率 6.993 kW；
- 一次/二次峰值电流 211.843 A / 879.960 A；
- 两侧桥瞬时功率守恒残差不超过 9.54e-7 W；
- 理想阶跃失效波形和数据以 `ideal_edge_failure_*` 保留。

详细推导、失败分析和结论边界见 `output/pdf/EXP014_DAB_switching_regression_report.pdf`。
