# EXP-012 分段策略对宽频响应与内部电压保持能力的影响

## 研究目的

在同一个 24+24 细单元合成无源参照模型上，比较均匀分段、按绕组层分段和信息引导连续分段，寻找同时保持外部端口响应、关键模态和内部电压应力所需的最小粗模型规模。

## 方法主线

细模型由完整电感矩阵、Maxwell 型电容矩阵、正电阻和支路关联矩阵构成。粗模型不重新拟合参数，而是通过组内等流的支路映射和分段线性节点电压映射进行能量等效聚合。信息引导边界由内部电压特征和局部绕组间电容的端口灵敏度特征共同决定，并强制保持空间连续。

## 主要结果

- 三类模型的端口误差都极小，但内部相邻电压应力误差可超过 10%，说明端口等效不保证内部状态保真。
- 在本次事后设置的试探性阈值下，信息引导模型从每绕组 8 段开始同时达标；均匀和物理分段在测试规模内未同时满足全部阈值。
- 每绕组 12 段的信息引导模型内部峰值误差约 0.0019%，相邻电压应力误差约 0.441%，矩阵维度由 48 降到 24。

## 结论边界

这是合成常参数模型上的方法筛选，不是 FEM 或样机验证。精度阈值是在观察初步结果后设定，只用于选择下一轮模型，不能作为预注册的确认性证据。当前信息特征含有细模型内部电压，属于 oracle/离线设计信息；下一版必须拆分为 oracle 模态分段和仅端口 Fisher 分段。
