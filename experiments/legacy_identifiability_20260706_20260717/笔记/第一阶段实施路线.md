# 第一阶段实施路线

## 目标

先不做完整在线系统，只做一个可验证的小闭环：

```text
给定高频变压器简化模型 + 给定 PWM 激励
-> 计算频域响应
-> 计算参数灵敏度
-> 构造信息矩阵
-> 判断参数可辨识性
```

## 第一版模型

先用低维模型，不要一开始上完整单匝梯形网络。

推荐第一版参数：

```text
theta = [Lsigma, Cp, Rac]
```

含义：

- `Lsigma`：漏感或等效串联电感。
- `Cp`：等效寄生电容，可代表绕组间/对地综合电容。
- `Rac`：高频等效绕组电阻。

可用一个简单端口模型表达：

```text
Zs(w) = Rac + j*w*Lsigma
Yp(w) = j*w*Cp
```

根据测量配置定义响应，例如：

```text
H(w, theta) = Vout(w) / Vin(w)
```

或者直接用：

```text
Zin(w, theta)
```

第一版建议先用 `Zin`，因为更容易和等效参数对应。

## 激励设计

比较这些运行波形：

1. 上升沿变化：

```text
tr = 50 ns, 100 ns, 200 ns
```

2. 开关频率变化：

```text
fs = 50 kHz, 100 kHz, 200 kHz
```

3. 占空比变化：

```text
D = 0.3, 0.5, 0.7
```

4. 可选：短时小扰动片段：

```text
fs 或 D 在几个周期内轻微变化
```

输出每种激励的频谱：

```text
|U(w)|^2
```

## 灵敏度计算

第一版用有限差分就够：

```text
S_i(w) = [H(w, theta + delta_i) - H(w, theta - delta_i)] / (2 * delta_i)
```

注意参数量纲差别很大，建议使用归一化灵敏度：

```text
S_i_norm(w) = dH / dlog(theta_i)
            ~= theta_i * dH / dtheta_i
```

这样 `Lsigma`、`Cp`、`Rac` 才能公平比较。

## 信息矩阵

第一版：

```text
I = sum_w |U(w)|^2 * S(w)^H * S(w)
```

更完整版本：

```text
I = sum_w S(w)^H * Rn(w)^-1 * S(w) * |U(w)|^2
```

如果有输入输出相干性，可加：

```text
I = sum_w gamma2(w) * |U(w)|^2 * S(w)^H * Rn(w)^-1 * S(w)
```

## 评价指标

每个工况输出：

```text
rank(I)
lambda_min(I)
cond(I)
det(I)
trace(inv(I))
diag(inv(I))
```

解释：

- `rank(I)`：能辨识几个独立参数方向。
- `lambda_min(I)`：最弱参数方向的信息量。
- `cond(I)`：反演病态程度。
- `det(I)`：整体信息体积，常用于 D-optimal design。
- `trace(inv(I))`：总参数方差，常用于 A-optimal design。
- `diag(inv(I))`：每个参数的理论方差下界。

## 参数耦合分析

计算参数协方差近似：

```text
Cov(theta) ~= inv(I + lambda*I0)
```

再计算相关系数：

```text
corr_ij = Cov_ij / sqrt(Cov_ii * Cov_jj)
```

如果 `corr(Lsigma, Cp)` 接近 1 或 -1，说明两者在当前激励下难以分离。

## 预期图表

第一阶段至少做这些图：

1. 不同 PWM 上升沿下的输入频谱。
2. 各参数归一化灵敏度随频率变化曲线。
3. 不同激励下 `cond(I)` 对比柱状图。
4. 不同激励下 `diag(inv(I))` 对比。

6. 最有信息频段分布。

## 与高频变压器物理结合

可辨识性结果要能解释成物理结论：

- 高频段更有利于辨识 `Cp`。
- 中低频或谐振附近更有利于辨识 `Lsigma`。
- `Rac` 需要足够的损耗敏感度，否则和噪声混在一起。
- 上升沿越快，高频信息越强，但测量链路和 EMI 问题越严重。
- 只测单端口可能导致 `Cp` 和 `Lsigma` 耦合，多端口测量能改善条件数。

## 第二版扩展

第一版完成后，再扩展：

1. 从三参数模型扩展到梯形网络：

```text
theta = [R_i, L_i, C_i, G_i, M_ij]
```

2. 从单输出响应扩展到多端口响应：

```text
H = [H11, H12, H21, H22, ...]
```

3. 从有限差分扩展到：

- 解析雅可比
- 伴随网络
- 自动微分

4. 从信息矩阵评价扩展到实际反演：

- 非线性最小二乘
- RLS
- EKF/UKF
- TSVD 可辨识方向更新

## 最小可交付成果

第一阶段结束时应形成：

1. 一个简单模型脚本。
2. 一组 PWM 激励频谱。
3. 一组灵敏度曲线。
4. 一张可辨识性评价表。
5. 一个结论：

```text
在某些运行脉冲和测量配置下，哪些参数可辨识；
哪些参数不可辨识或只能组合辨识；
哪些工况最适合在线诊断。
```
