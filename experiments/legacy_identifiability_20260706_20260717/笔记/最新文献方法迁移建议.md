# 最新文献方法迁移建议

生成时间：2026-07-07

## 当前实验结果怎么理解

当前结果不是失败，而是暴露了真正的问题：

1. 单端口观测对多寄生参数不够，`Y11` 只能辨识部分参数组合；
2. 多端口互导纳 `Y12` 对完整辨识非常关键；
3. Fisher 信息矩阵能预测趋势，但在病态、非线性、噪声和参数耦合下不能替代实际反演误差；
4. 频点、端口、PWM 片段都应该被当成“实验设计变量”，而不是固定不变。

## 最值得迁移的最新方法

### 1. EIS 频点优化：最贴近本项目

代表文献：

- `Optimizing Experiments for Accurate Battery Circuit Parameters Estimation: Reduction and Adjustment of Frequency Set Used in Electrochemical Impedance Spectroscopy`, 2025

可迁移内容：

- 用 CRLB/FIM 判断等效电路参数不确定性；
- 用 E-optimal design 最大化 Fisher 信息矩阵最小特征值；
- 不盲目增加所有频点，而是选择最能降低参数方差的频点；
- 适合迁移到高频变压器的宽频阻抗/导纳辨识。

建议我们下一步做：

> 频点子集选择实验：从 600 个频点中选 20/40/80 个频点，比较参数 RMSE 和 Fisher 指标。

### 2. Bayesian optimal input design：解决局部 Fisher 太乐观的问题

代表文献：

- `An Approximate Bayesian Approach to Optimal Input Signal Design for System Identification`, 2025

可迁移内容：

- 不只在一个标称参数点算 Fisher；
- 用参数先验分布下的平均信息量或互信息衡量输入好坏；
- 适合我们处理参数真值未知、老化状态未知的问题。

建议我们做：

> 对 `Lsigma/Cps/Cg/Rac/Gg` 设定先验范围，用 prior-averaged FIM 选择 PWM 条件和测量端口。

### 3. Observability-aware active calibration：适合做运行片段选择

代表文献：

- `Observability-Aware Active Calibration of Multi-Sensor Extrinsics for Ground Robots via Online Trajectory Optimization`, 2025

可迁移内容：

- 用 `lambda_min(FIM)` 衡量片段可观测性；
- 在线选择最有信息量的数据片段；
- 不必把所有运行数据都拿来辨识。

建议我们做：

> 在线运行数据中滑窗计算 FIM，只保留高信息量 PWM 片段用于参数更新。

### 4. Practical identifiability / profile likelihood：判断哪些参数必须合并

代表文献：

- `A Systematic Computational Framework for Practical Identifiability Analysis in Mathematical Models Arising from Biology`, 2025

可迁移内容：

- Fisher 不满秩或病态时，不一定要硬辨识所有参数；
- 应判断哪些参数是结构不可辨识，哪些只是噪声下不可辨识；
- 对不可辨识参数做重参数化、合并或正则化。

建议我们做：

> 对多端口模型做 profile likelihood 或参数扫描，判断 `Cg/Gg/Cps` 哪些组合需要合并。

### 5. Reinforcement learning / active OED：后期再做

代表文献：

- `Real-Time Optimal Design of Experiment for Parameter Identification of Li-Ion Cell Electrochemical Model`, 2025
- `Optimal Design of Experiment for Electrochemical Parameter Identification of Li-ion Battery via Deep Reinforcement Learning`, 2025

可迁移内容：

- 把激励设计写成策略优化问题；
- 动态选择输入波形，使参数可辨识性最大；
- 适合未来做“诊断友好型 PWM”。

但现阶段不建议先做，因为工程复杂度高，容易偏离高频变压器主线。

## 我们下一步最应该做什么

优先级最高的是：

1. 多端口频点选择实验；
2. prior-averaged FIM，而不是单点 FIM；
3. Monte Carlo 验证被选频点是否真的降低参数方差；
4. 对不可辨识参数做合并或降维。

也就是说，下一步实验建议是：

> `多端口 Y 矩阵 + E-optimal 频点选择 + prior-averaged FIM + Monte Carlo 参数反演`

这一步最容易形成论文贡献：

> 面向运行陡脉冲高频变压器在线宽频辨识的端口-频点-激励联合可辨识性设计。
