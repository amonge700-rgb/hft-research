# 2026 CCF-A 相关开源代码调研

时间：2026-07-10

目标：查找今年或近两年 CCF-A/顶会中，能迁移到“高频变压器在线宽频辨识”的开源代码。

## 先说结论

严格限定：

```text
2026 年
+ CCF-A
+ 系统辨识 / 机器人控制 / 在线实验设计
+ 有成熟开源代码
+ 能直接迁移到高频变压器
```

这样的项目目前很少，几乎没有“一拿来就能用”的仓库。

但如果把口径放宽到“近两年 CCF-A/顶会开源方法 + 可迁移工具”，就能找到几类很有价值的工程：

1. Bayesian Experimental Design / Sequential OED；
2. 物理模型 + 残差学习；
3. 可微分动力学 / Neural ODE；
4. 稀疏系统辨识；
5. 宽频频响 Vector Fitting。

对我们最有用的不是机器人任务本身，而是它们背后的方法：

```text
有限观测下主动选择激励
模型失配下保持鲁棒
物理模型与学习残差结合
用不确定性指导下一次实验
```

## 今年/近两年最值得关注的开源项目

### 1. ContrastiveDiffusions

仓库：

`https://github.com/jcopo/ContrastiveDiffusions`

论文信息：

仓库说明为 `Bayesian Experimental Design via Contrastive Diffusions (ICLR 2025 Spotlight)`。

用途：

```text
Bayesian Experimental Design
用扩散/对比方法选择实验设计
```

对我们的迁移方式：

```text
实验设计变量：
  频点集合
  PWM 上升沿
  占空比
  开关频率
  端口激励组合

目标：
  最大化参数信息增益
  或最大化模型区分能力
```

评价：

很适合作为“新方法来源”。但它可能偏复杂，第一步不一定直接复现全文，可以先借它的信息增益/对比式设计思想。

### 2. dad: Deep Adaptive Design

仓库：

`https://github.com/ae-foster/dad`

说明：

`Deep Adaptive Design: Amortizing Sequential Bayesian Experimental Design`

用途：

```text
Sequential Bayesian Experimental Design
每次观测后自适应决定下一次实验
```

对我们的迁移方式：

```text
第 k 次采样得到部分频响/时域波形
-> 更新参数后验
-> 决定第 k+1 个频点/脉冲参数/测量端口
```

评价：

非常贴合“在线宽频辨识”。它的思想比传统一次性 FIM-OED 更适合在线场景。

### 3. amortized-decision-aware-bed

仓库：

`https://github.com/huangdaolang/amortized-decision-aware-bed`

说明：

`Amortized Bayesian Experimental Design for Decision-Making (NeurIPS 2024)`

用途：

```text
不是为了把所有参数估得最准
而是为了让最终决策更好
```

对我们的迁移方式：

这点很关键。我们的目标不是估计每个寄生参数都极准，而是：

```text
判断宽频响应是否异常
判断谐振点是否靠近工作频段
判断绝缘/局放风险是否上升
```

所以实验设计目标可以从：

```text
min parameter error
```

升级为：

```text
min risk decision error
```

评价：

非常有论文味。它能帮我们把“参数辨识”变成“面向风险判断的辨识”。

### 4. microsoft/co-bed

仓库：

`https://github.com/microsoft/co-bed`

说明：

`CO-BED: Information-Theoretic Contextual Optimization via Bayesian Experimental Design`

用途：

```text
带上下文的 Bayesian Experimental Design
```

对我们的迁移方式：

上下文可以是：

```text
负载状态
温度
运行功率
开关频率
端口接线状态
历史健康状态
```

评价：

适合第二阶段。第一阶段先做无上下文版本，后续再加运行工况上下文。

### 5. AutoOED

仓库：

`https://github.com/yunshengtian/AutoOED`

说明：

`Automated Optimal Experimental Design Platform`

用途：

多目标实验设计平台。

对我们的迁移方式：

可以做基线或界面参考：

```text
目标1：响应拟合误差低
目标2：参数方差低
目标3：激励能量小
目标4：不影响运行安全
```

评价：

工程平台感强，但与我们具体物理模型耦合需要自己做。

### 6. sOED

仓库：

`https://github.com/wgshen/sOED`

说明：

`Approximate dynamic programming and policy gradient based sequential optimal experimental design`

用途：

Sequential OED，强调动态决策。

对我们的迁移方式：

适合把在线辨识写成序贯决策：

```text
state = 当前参数后验 / 不确定性
action = 选择下一段 PWM 或频点
reward = 信息增益 - 激励成本 - 风险代价
```

评价：

思想上非常贴合，但工程迁移可能比 BoTorch/GPyTorch 难。

### 7. PySINDy

仓库：

`https://github.com/dynamicslab/pysindy`

说明：

稀疏非线性动力学系统辨识库。

用途：

```text
从时域数据自动发现动力学方程
```

对我们的迁移方式：

可以作为“物理残差项发现”工具：

```text
物理等效电路解释不了的残差
-> 用稀疏库寻找可能的频率/状态依赖项
```

评价：

不是第一优先级，但适合做可解释 AI 对照。

### 8. GPyTorch / BoTorch

仓库：

`https://github.com/cornellius-gp/gpytorch`

网站：

`https://botorch.org/`

用途：

```text
高斯过程
贝叶斯优化
不确定性建模
主动采样
```

对我们的迁移方式：

最实用的第一步：

```text
用 GP 建模参数误差/模型残差
用 BoTorch 选下一组频点或 PWM 参数
```

评价：

我建议作为第一批真实上手工具。成熟、文档好、和 PyTorch 生态兼容。

## Hugging Face 情况

搜索了：

- `system identification`
- `neural ode`
- `robot dynamics identification`
- `battery state estimation neural ode`
- `impedance spectroscopy`

结论：

Hugging Face 上相关模型很少，而且下载量/维护度很低。暂时不建议依赖 HF 模型作为主线。

HF 未来可以作为补充：

```text
时间序列 foundation model 基线
或波形异常检测模型
```

但不是现在最值得投入的方向。

## 和我们课题的对应关系

| 我们的问题 | 可迁移开源方向 | 代表工程 |
|---|---|---|
| 哪些频点最有信息 | Bayesian Experimental Design | `dad`, `ContrastiveDiffusions`, `BoTorch` |
| 在线下一步测什么 | Sequential OED | `dad`, `sOED` |
| 模型不准怎么办 | residual learning / GP residual | `GPyTorch`, PyTorch 自写 |
| 参数不一定都服务最终目标 | decision-aware BED | `amortized-decision-aware-bed` |
| 从波形发现缺失项 | sparse identification | `PySINDy` |
| 频响转宏模型 | Vector Fitting | `scikit-rf`, MATLAB VF |

## 推荐下一步

不要直接复现机器人大模型，也不要硬上 Hugging Face。

建议做一个很小的“CCF-A 方法迁移实验”：

```text
对象：
  高频变压器复杂真值模型

候选设计：
  频点 / PWM 参数 / 端口组合

方法：
  1. 均匀采样
  2. 传统 FIM-OED
  3. GP/BoTorch Bayesian OED
  4. Sequential BED 思想下的逐步选点

评价：
  响应拟合误差
  参数后验方差
  模型失配下鲁棒性
  风险指标判断准确率
```

这条路线的创新表述可以是：

```text
借鉴 CCF-A 机器学习会议中的 Bayesian Experimental Design 与主动辨识思想，
提出面向高频变压器在线宽频辨识的模型失配鲁棒频点/激励选择方法。
```
