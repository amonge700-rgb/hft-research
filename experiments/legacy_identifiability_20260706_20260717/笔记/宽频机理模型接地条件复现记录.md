# 宽频机理模型接地条件复现记录

对象：Liu et al., Wideband Mechanism Model and Parameter Extracting for High-Power High-Voltage High-Frequency Transformers, IEEE TPEL 2016.

## 使用数据

- Table I: 20 kHz, 30 kVA, ratio 1:91.3, LV 12 turns, HV 1096 turns.
- Table II: Lm=4.587 mH, Ls0=42.45 mH, Rm=422.8 Ohm, Zs1/Zs2.
- Table III: C12, C34, C24, C13, C23, C14, C10, C20, C30, C40.
- Table IV: grounding-condition resonant frequencies.

## 模型说明

本脚本把 Table III 构造成四端子电容矩阵，并把磁性部分近似成差模两端口网络。它不是作者完整 Fig. 6 电路仿真器，因此结果用于趋势复现和下一步在线 PWM 目标构造，不作为严格原文复现实验。

Best orientation: leakage_referred_to_HV. Capacitance global scale after f1 calibration: 0.9874.

## 判断

该文献数据适合补充结构/FEM参数来源。后续可用该模型生成更接近结构机理的对象，再接入在线 PWM 特征频率恢复实验。主线仍然是在线 PWM；该实验负责让在线 PWM 的对象更像文献中的高频变压器，而不是自定义曲线。
