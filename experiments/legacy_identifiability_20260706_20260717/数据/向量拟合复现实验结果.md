# 向量拟合复现实验结果

生成时间：2026-07-07

## 实验 1：理想高频变压器阻抗曲线拟合

脚本：

- `run_vector_fitting_hft_demo.m`

输出：

- `vf_hft_demo_fit.png`
- `vf_hft_demo_error.png`
- `vf_hft_demo_response.csv`
- `vf_hft_demo_SER.mat`
- `vf_hft_demo_summary.txt`

模型：

`Z = (Rac + s Lsigma) parallel Cp`

参数：

- `Lsigma = 2e-6 H`
- `Cp = 200e-12 F`
- `Rac = 0.2 Ohm`
- 频率范围：1 kHz 到 10 MHz
- Vector Fitting 阶数：6

结果：

- 平均相对误差：`1.342e-14`
- 最大相对误差：`3.847e-13`

结论：

SINTEF 的 `vectfit3` 可以非常稳定地拟合这个第一版高频变压器阻抗模型。这个结果说明后续可以把 Vector Fitting 作为“宽频响应压缩成低阶有理模型”的复现基础。

## 实验 2：带噪声响应 + PWM 权重拟合

脚本：

- `run_vector_fitting_noise_weight_demo.m`

输出：

- `vf_noise_weight_fit.png`
- `vf_noise_weight_error.png`
- `vf_noise_weight_pwm_weights.png`
- `vf_noise_weight_metrics.csv`
- `vf_noise_weight_demo.mat`
- `vf_noise_weight_summary.txt`

噪声设置：

- 幅值噪声：1%
- 相位噪声：0.2 degree

比较三种拟合权重：

| case | meanRelErrTrue | maxRelErrTrue | meanRelErrTrueHighFreq |
|---|---:|---:|---:|
| uniform | 6.845e-4 | 4.421e-3 | 3.066e-4 |
| pwm_best_tr50ns_fs500k_D03 | 1.269e-3 | 2.657e-2 | 2.020e-3 |
| pwm_weak_tr500ns_fs50k_D07 | 2.727e-4 | 1.773e-2 | 5.238e-4 |

## 重要判断

这个结果说明：`激励可辨识性权重` 和 `拟合误差权重` 不能简单画等号。

第一轮 Fisher 信息分析回答的是：

> 哪种 PWM 激励更有利于参数被观测？

第二轮带噪声 Vector Fitting 回答的是：

> 给定一条有噪声的频响曲线，拟合器应该更相信哪些频点？

这两个问题相关，但不是同一个问题。

## 下一步实验建议

下一步不要继续只比较拟合曲线误差，而应直接比较“参数反演误差”：

1. 用已知参数生成 `Ztrue(f)`；
2. 加入噪声得到 `Zmeas(f)`；
3. 对不同 PWM 条件下的频点权重或可观测频段做筛选；
4. 反演 `Lsigma, Cp, Rac`；
5. 用 Monte Carlo 重复 100 次，比较参数估计方差。

这样才和“可辨识性分析”的目标完全一致。
