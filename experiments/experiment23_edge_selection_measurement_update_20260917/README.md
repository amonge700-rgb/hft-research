# EXP-023：逐匝耦合边选择与测量条件化更新

目标不是用GNN直接预测响应，而是让网络输出两类具有物理意义的结果：

1. 静态边重要性：在固定边预算下，应保留哪些匝对电容/互感耦合；
2. 动态边更新：由DAB多窗口两端口观测判断哪些耦合发生变化，并估计其对数变化量。

网络输出重新组装为Maxwell电容矩阵和对称正定电感矩阵，最终误差由物理矩阵/Kron求解器计算。本实验仍是仿真级最小实现，采用EXP-021的12个COMSOL参数化几何，按几何划分8/2/2训练、验证和测试集。

运行：

```powershell
python run_exp23.py --quick
python run_exp23.py --epochs 350 --states 70
```
