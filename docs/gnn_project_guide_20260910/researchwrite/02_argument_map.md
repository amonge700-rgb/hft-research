# Argument map

1. A turn-level coupled transformer is naturally represented by matrices and a heterogeneous graph.
2. EXP15 provides an exact differentiable circuit teacher; EXP16 tests a FALCON-style graph baseline and reveals inverse ill-conditioning.
3. EXP17 shows that response accuracy does not imply parameter uniqueness and motivates Fisher/OED and low-dimensional correction coordinates.
4. EXP18 asks whether explicit relation types and edge-centric messages improve prediction of port, internal, and edge quantities across topology sizes and unseen DAB conditions.
5. Results support the route but do not yet constitute online identification or engineering validation.
6. The next implementation must add a measurement encoder and identify only physically/Fisher-supported latent graph corrections, decoded through the exact matrix solver.
