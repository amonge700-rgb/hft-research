# 下一阶段实验路线（EXP-018 及以后）

## 当前证据

- EXP-016 已跑通匝级图代理与物理矩阵闭环，但 HFT 分型 GNN（MAE 0.0538）未优于 FALCON 风格同质基线（MAE 0.0521）。
- EXP-017 表明八参数虽然形式满秩，但全端口 Jacobian 条件数约 2225；单独使用 `Y11`、`Y22` 或 `Y12` 的条件数达到 `10^8`--`10^10` 量级。
- 六个 log-det OED 频点将条件数由均匀六频点的约 6907 降到约 2109。
- 在 100 次带噪 Monte Carlo 中，OED + 四维低秩子空间把平均参数误差从全八参数的 12.59% 降到 3.20%。
- EXP-017 尚未使用真实 PWM 频谱权重，也未使用 DAB 多运行窗口。因此它是理想频域 OED，不是完整在线实验。

## EXP-018：PWM 加权的 DAB 多窗口 Fisher/OED

### 研究问题

把早期“PWM 边沿和频谱信息密度”结论，与 EXP-017 的多端口 Fisher/低秩子空间正式结合：

> 在不额外停机扫频的条件下，哪些 DAB 自然运行窗口和 PWM 谐波真正能够稳定辨识 `Cps` 及其可辨识耦合参数？

### 数据链

1. 复用 EXP-014 的 DAB 开关模型生成同步 `v1,i1,v2,i2`；
2. 扫描相移角、电压比、负载、上升时间/带宽和必要的死区设置；
3. 对每个窗口计算频谱能量、相干度和噪声方差；
4. 由多窗口电压矩阵检查最小奇异值与条件数；
5. 将实际可用频谱写入 Fisher 权重，而不是假设每个频点等权。

### 核心公式

对于窗口 `r`、频点 `k`：

\[
\mathbf i_{r,k}=\mathbf Y(\omega_k;\theta)\mathbf v_{r,k}+\epsilon_{r,k}.
\]

参数灵敏度为

\[
\mathbf J_{r,k}=\frac{\partial[\mathbf Y(\omega_k;\theta)\mathbf v_{r,k}]}{\partial\log\theta}.
\]

PWM/测量权重可写为

\[
w_{r,k}=\frac{\gamma_{r,k}^2\|\mathbf v_{r,k}\|_2^2}{\sigma_{r,k}^2+\varepsilon},
\qquad
\mathbf F=\sum_{r,k}w_{r,k}\mathbf J_{r,k}^H\mathbf J_{r,k}.
\]

特征频率 `f1`、`fu`、`fzero` 作为候选频带先验，而不是直接替代 Fisher 选择。

### 对照组

1. 常规 20 kHz PWM 单窗口；
2. 早期定点二值 PWM；
3. 理想等权 log-det OED；
4. PWM 频谱加权 OED；
5. 物理特征频带 + PWM 加权 OED；
6. 多 DAB 运行窗口联合 OED。

### 参数层级

- 全八参数仅作为病态性对照；
- EXP-017 Fisher 原参数子集：`R_p, L_leak, C_ground, C_ps`；
- EXP-017 四维 Fisher 主子空间；
- 若目标聚焦 `Cps`，将 `Ls/L_leak` 作为联合估计或干扰参数，禁止错误固定。

### 验收指标

- Fisher 最小特征值、log-det 和条件数；
- 多窗口激励矩阵的最小奇异值；
- `Cps`、漏感及低秩坐标的均值、标准差和 95% 误差；
- 完整端口响应误差和未选频点外推误差；
- 所需窗口数、记录长度、额外 RMS 电流和功率扰动；
- 与均匀频点、固定特征频点的统计显著差异。

### 判定规则

如果 PWM 加权后目标高频没有足够能量，不能把理想 OED 频点直接称为“在线可测”。如果增加窗口仍不能显著抬升最小特征值，应减少在线参数维数，而不是让 AI 强行输出不可辨识参数。

## EXP-019：局部边扰动与 HFT 异构 GNN

只有 EXP-018 明确在线可观测坐标后，才重新训练 GNN。数据不再只使用八个全局尺度，而应包含：

- 相邻匝电容局部变化；
- 原副边面对区域的局部跨绕组电容变化；
- 主磁通与漏磁通的不同低秩扰动；
- 不同匝数和绕组排列。

届时比较同质 FALCON、HFT 分型 GNN 和物理矩阵解码器，并增加边级/内部电压任务。这样异构关系才具有真实辨别价值。

## 数据真实性升级

合成实验之后按以下顺序升级：

1. COMSOL 静电提取匝级 Maxwell 电容矩阵；
2. 磁场或频域求解提取电感/阻抗矩阵；
3. 用端口扫频验证矩阵组网；
4. 用少量实测数据校准测量链路；
5. 最后开展有载 DAB 在线验证。
